Programming Challenge: Snack Order Checker

Your task: Create a program for a school snack shop.

  1. Ask the student for their name.
  2. Ask how many snacks they want and convert it to an integer.
  3. Ask how many drinks they want and convert it to an integer.
  4. Calculate the total number of items using +.
  5. Use if and else: if the total is 5 or more, print Large order; otherwise print Small order.
  6. Print the student's name and the total.
Target level: input(), int(), variables, addition, print(), if/else and correct indentation.
