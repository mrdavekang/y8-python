Mission 1

What is a Python list?

A list stores many values inside one variable. Think of it like a game backpack.

Light Reading

Instead of creating many separate variables...

item1 = "sword"
item2 = "potion"
item3 = "shield"

Python lets us store them together in a list:

inventory = ["sword", "potion", "shield"]
Key idea: Lists keep items in order.

Vocabulary

ListStores many values
ItemOne value inside a list
IndexThe position number

Mission 2

Index starts at 0

Python does not count list positions from 1. It starts from 0.

The most important table today

inventory = ["sword", "potion", "shield", "map"]
print(inventory[0])  # sword
print(inventory[2])  # shield
Common mistake: inventory[4] will crash here because the list only has indexes 0, 1, 2 and 3.

Circle Coordinates
