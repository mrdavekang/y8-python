Build your first web page with HTML

Learn how tags structure a page, how text can be formatted, and how inline CSS changes colour, font, and appearance.

1. What is HTML?

HTML stands for HyperText Markup Language. It uses tags to organise text, headings, lists, and other parts of a web page.

Think of HTML tags like building blocks. Each block gives structure to the page.
<h1>My First Website</h1>
<p>This is my first paragraph.</p>

2. Opening and closing tags

Opening tag

The opening tag starts the instruction.

<p>

Closing tag

The closing tag ends the instruction. It normally uses a slash.

</p>
<p>This text is inside a paragraph tag.</p>

3. Useful HTML tags

These tags help students structure and format simple web pages.

<h1><h2><p><b><em><q><ul><li>

<h1>My Hobby</h1>
<p>I enjoy <b>coding</b> websites.</p>
<p>HTML can be <em>creative</em>.</p>

4. Inline CSS with style

The style attribute changes the appearance of one HTML element. Use American spelling: color, not colour.

<h2 style="color:red;">Important title</h2>
<p style="font-family:Arial;">This paragraph uses Arial.</p>
Inline CSS is useful for practice, but changing many tags one by one can take a long time.
